Deployment Guide

🐧 Read this before you upload — it'll save you pain.

⚠️ Rule #1: Use relative links only

Your site is served from a subfolder of our domain, not from the root. That means any link starting with / will break — it points to the root of the whole domain, not to your site.

❌ Broken — don't do this 
<a href="/about">About</a>
<img src="/images/logo.png">
<link rel="stylesheet" href="/style.css">
<script src="/app.js"></script>

When a visitor clicks /about, the browser goes to ourdomain.com/about — completely outside your site — and gets a 404.

✅ Correct — do this instead 
<a href="about/">About</a>
<img src="images/logo.png">
<link rel="stylesheet" href="style.css">
<script src="app.js"></script>

Rule of thumb: never start a link with /. Use bare relative paths.

📁 Rule #2: One folder per page

Every "page" should be a folder with an index.html inside it. That's how you get clean URLs like /about/ instead of /about.html.

You want this URLPut this file on disk
/ (homepage)index.html
/about/about/index.html
/blog/blog/index.html
/blog/post-1/blog/post-1/index.html
/images/logo.pngimages/logo.png
/style.cssstyle.css
❌ Does NOT work 
index.html
about.html      ← page sitting loose at top level
contact.html

If about.html is at the top level, there's no way to reach it by typing /about. Either rename it to about/index.html, or link to it as about.html directly.

🐧 A valid example ZIP

Here's what a well-structured upload looks like:

my-website.zip ├── index.html ├── style.css ├── app.js ├── images/ │ └── logo.png ├── about/ │ └── index.html └── contact/ └── index.html

And index.html looking like this:

<!DOCTYPE html>
<html>
<head>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <nav>
    <a href="about/">About</a>
    <a href="contact/">Contact</a>
  </nav>
  <img src="images/logo.png" alt="Logo">
  <script src="app.js"></script>
</body>
</html>

Notice every href and src is relative — no leading slashes.

🚫 Single-page apps (React, Vue, Svelte)

If your site uses a client-side router, use hash routing. We don't do SPA fallback — we won't silently serve index.html for unknown routes.

❌ Won't work 
<BrowserRouter>
  <Route path="/about" element={<About />} />
</BrowserRouter>

Navigating to /about asks our CDN for /about, which doesn't exist → 404.

✅ Will work 
<HashRouter>
  <Route path="/about" element={<About />} />
</HashRouter>

URLs become #/about, which never hit the server, so nothing breaks.

❌ Don't zip these

  • node_modules/
  • .git/
  • .DS_Store, __MACOSX/ — we ignore these automatically
  • Thumbs.db
  • Cache folders, IDE configs

✅ Do zip these

  • Your index.html
  • CSS, JS, images, fonts
  • Any other asset your page loads

📝 Pre-upload checklist

  • Every internal link uses a relative path (no leading /)
  • Homepage is index.html at the ZIP root (or inside one wrapper folder)
  • Every sub-page is its own folder with an index.html inside
  • No node_modules, .git, or cache folders in the ZIP
  • ZIP is under 50 MB
  • All assets load when you open index.html locally in your browser

❓ FAQ

Why can't I use /about links?

Because your site lives at a subpath of our domain, not at the domain root. /about would send visitors to a completely different site.

My site works locally but breaks after upload. Why?

Almost always the leading-slash problem. Open DevTools → Network tab, click a broken link, and look at the URL it tried to load. If it starts with the bare domain instead of your site's folder, that's the bug.

Can I use absolute URLs to my own domain?

No — you don't have your own domain, you have a subpath of ours. Use relative URLs for everything internal.

Can I link to external sites?

Yes, of course. https://google.com or https://cdn.jsdelivr.net/... work fine, as long as they're fully qualified with https://.

Can I update my site after uploading?

Re-upload a new ZIP and you'll get a new URL. Bookmark or share the new one — old uploads are not automatically redirected.

How do I get clean URLs like /about/ instead of /about.html?

Put the page in its own folder with an index.html. See the structure rules above.

That's it. Upload your ZIP, grab the URL, and share it with the world. 🐧
